# Entrega M3.4 — Demonstração integrada

Data: 10/10/2026. Estado: implementado e validado no escopo abaixo. Commit de origem: `Neste commit`.

## Objetivo e funcionalidades

Teste Chrome + Next + API + MariaDB, evidências desktop/mobile, correção do cabeçalho Swagger e consolidação documental.

## Regras de negócio e integridade

Jornada respeita permissões reais da casa; dados sintéticos em banco efêmero; nenhum envio externo. Morador sem login, editor autorizado e leitor sem edição funcionam pela aplicação integrada.
